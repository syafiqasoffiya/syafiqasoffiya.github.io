## 1. How to Deploy on GitHub Pages

1. **Create a GitHub Account** (if you do not already have one) at [github.com](https://github.com).
2. **Create a New Repository**:
   - Click the **+** icon in the top-right corner and select **New repository**.
   - Name it `my-portfolio` (or `<your-github-username>.github.io` if you want it as your main GitHub Pages site).
   - Set visibility to **Public** and click **Create repository**.
3. **Upload the Project Files**:
   - Unzip `my-portfolio-v4.zip` on your computer.
   - Inside your new GitHub repository, click **uploading an existing file**.
   - Drag and drop all files and folders from inside `my-portfolio-v4/` (`index.html`, `styles.css`, `script.js`, `README.md`, and the `assets/` folder).
   - Click **Commit changes**.
4. **Enable GitHub Pages**:
   - Go to your repository's **Settings** tab.
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment → Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. **View Your Live Website**:
   - Wait 1–2 minutes, then refresh the Pages settings screen. Your live URL will appear at the top (e.g., `https://<your-username>.github.io/my-portfolio/`).

---

## 2. How to Save the Portfolio as a PDF

- Click any **Save PDF** / **Save as PDF** button on the website (available in the top navigation bar, Hero section, and Contact section).
- In the browser dialog that opens, set **Destination** to **Save as PDF** (ensure *Background graphics* is checked for full color badges) and click **Save**.
- The built-in `@media print` stylesheet automatically formats the portfolio onto clean A4 pages, hides navigation bars/buttons, and keeps links clickable.
