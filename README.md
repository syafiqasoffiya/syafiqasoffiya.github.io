# Nur Syafiqa — Academic & IT Portfolio

A responsive, single-page professional portfolio built with HTML, CSS and a little JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/` — add your CV PDF and optional images here

## Before publishing
1. Replace `YOUR.EMAIL@example.com` with your professional email.
2. Add your LinkedIn profile URL.
3. Fill in the exact Master's and Bachelor's programme, university and graduation years.
4. Add your CV PDF as `assets/cv.pdf`.
5. Add verified publication links, certificates and conference outputs if you want them displayed.
6. Review every detail for accuracy before making the site public.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, `README.md` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. Your site will be available at `https://yourusername.github.io`.

If you use a repository with another name, the site URL will usually be `https://yourusername.github.io/repository-name/`.

## Important privacy note
Only publish information you are comfortable making public. Avoid personal identification numbers, home address, private family details and documents containing sensitive data.
